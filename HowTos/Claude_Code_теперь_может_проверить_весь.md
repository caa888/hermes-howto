# Claude Code теперь может проверить весь


![Иллюстрация](//telegram.org/img/emoji/40/F09F8C9A.png)


## Содержание
Claude Code теперь может проверить весь проект и вернуть пару строк В Code Mode Claude пишет короткий скрипт на JavaScript. Просишь найти битые ссылки в документации — скрипт сам перебирает файлы и возвращает модели только список битых ссылок . Так в контексте остаётся больше места для самой задачи. Режим экспериментальный. Нужна нативная версия Claude Code 2.1.323 или новее , на Windows — ещё и Git for Windows. Работает в интерактивном терминале. В пользовательском settings.json добавь в раздел env "CLAUDE_CODE_EXPERIMENTAL_CODE_MODE": "1" , запусти Claude и подтверди включение. Инструкция для твоей ОС . 😎 КиберПоток / Навигация #новости #claude #ии
