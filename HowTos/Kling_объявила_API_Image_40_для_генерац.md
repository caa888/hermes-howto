# Kling объявила API Image 4.0 для генерации изображений 17 ноября Kling объявила ...

## Описание
Kling объявила API Image 4.0 для генерации изображений 17 ноября Kling объявила API Image 4.0. Модель создаёт одно изображение или серию до 10 изображений по одному запросу. Можно добавить до 10 изображений-референсов. Доступны разрешения 2K, 4K и нативное 8K. По заявлению компании, модель может размещать на изображении до 2000 символов. Русского языка в опубликованном списке поддерживаемых языков нет. Для дизайна страниц и карточек товаров доступен режим длинного изображения с разрешением 1K или 2K. Image 4.0 доступна в Kling Creative Studio и через API для разработчиков и предприятий. В API отдельно тарифицируются входные референсы и выходные изображения; цена последних зависит от разрешения.
