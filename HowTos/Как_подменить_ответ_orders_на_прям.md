# 🌐 Как подменить ответ /orders на [] прямо в Chrome Подмените ответ /orders на []...

## Описание
🌐 Как подменить ответ /orders на [] прямо в Chrome Подмените ответ /orders на [] в Chrome DevTools. Так можно проверить пустой экран заказов, пока сервер продолжает возвращать обычные данные. В Network нажмите на запрос правой кнопкой и выберите Override content . Укажите папку, сохраните [] вместо тела ответа и перезагрузите страницу. В том же файле можно проверить длинное название товара или пропущенное поле. После проверки отключите Local Overrides. Инструкция Chrome DevTools 🐸 Библиотека программиста
