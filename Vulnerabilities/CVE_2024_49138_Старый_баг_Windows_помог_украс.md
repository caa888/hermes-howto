# Уязвимость: CVE-2024-49138

## Детали
Старый баг Windows помог украсть данные 1 млн карт Злоумышленники похитили данные минимум миллиона банковских карт, заразив более 700 POS-терминалов в свыше 20 странах, преимущественно в Бразилии. Инфраструктуру атакующих специалисты нашли на открытом сервере вместе с исходниками малвари и панелью VINY JUNIOR TRILHAS. Для повышения привилегий на терминалах использовали CVE-2024-49138 в драйвере Windows Common Log File System, закрытую Microsoft ещё в декабре 2024 года. После получения прав системы зловред ставил троян удалённого доступа и перехватывал реквизиты при оплате. Одни не осилили патчи на кассах, другие — пароль на сервере Join our club Cult 👁
