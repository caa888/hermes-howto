# Уязвимость: CVE-2024-49138

## Детали
• Эксперты компании Cybernews&nbsp; обнаружили в открытом доступе инфраструктуру хакера, который взломал более 700&nbsp;POS‑терминалов в 20 странах. Также были раскрыты данные как&nbsp;минимум 1 млн. кредитных и дебетовых карт.&nbsp; • В отчете указано, что на сервере хакера был обнаружен исходный код вредоносного ПО, инструменты эксплуатации и панель управления. • Для осуществления атак хакер использовал уязвимость ( CVE-2024-49138 ) в драйвере Windows Common Log File System (CLFS), которая отвечает за работу системных журналов. Данная уязвимость позволяет получить привилегии system на хосте. Уязвимость требует предварительного доступа к системе и позволяет повысить права уже запущенного кода. Самое интересное здесь то, что Microsoft закрыли эту уязвимость еще в 2024 году. • Получив системные привилегии, вредоносное ПО устанавливало малварь для удаленного доступа, что позволило непрерывно собирать данные платежных карт в момент проведения транзакций. Среди данных оказались: ➡ Номер счета (PAN); ➡ Срок действия карты; ➡ ID номера банков (BIN); ➡ Страна, в которой выпускалась карта; ➡ Банки‑эмитенты; ➡ Тип и бренд карты. • Кроме того, в ходе атаки были получены сведения о 782 POS‑терминалах, включая версии используемых ими операционных систем и географическое местоположение. • Больше всего данных относится к Бразилии: именно там находилось большинство зараженных устройств, а база данных с украденными картами состояла преимущественно из карт, выпущенных бразильскими банками. На основании изученной документации и отчетов исследователи полагают, что сам атакующий также может находиться в этой стране. ➡️ https://cybernews.com/windows-bug-pos-terminals-stolen-credit-cards #Новости #Security
