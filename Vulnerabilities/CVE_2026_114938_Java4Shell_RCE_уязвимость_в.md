# Уязвимость: CVE-2026-114938

## Детали
Java4Shell - RCE-уязвимость в декодировщике Base64 из OpenJDK, затрагивающая многие Java-приложения Раскрыта информация о критической уязвимости (CVE-2026-114938) в OpenJDK, позволяющей добиться удалённого выполнения кода или утечки содержимого памяти процесса при атаке на написанные на языке Java проекты, использующие штатный декодировщик данных в формате Base64. Base64 применяется в протоколах аутентификации, при загрузке файлов на web-сервер, в электронной почте и во многих других ситуациях, требующих передачи бинарных данных в текстовом виде. Уязвимость приводит к записи контролируемых атакующим данных в память вне выделенного буфера и вызвана ошибкой в ассемблерных оптимизациях, использующих инструкции AVX-512 VBMI (Vector Byte Manipulation Instructions).
