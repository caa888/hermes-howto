# Уязвимость: CVE-2026-116331

## Детали
Уязвимость функций min() и max() системы управления базами данных PostgreSQL связана с ошибками смешения типов данных. Эксплуатация уязвимости может позволить нарушителю, действующему удаленно, выполнить произвольный код BDU:2026-19312 CVE-2026-116331 Использование рекомендаций производителя: https://www.postgresql.org/support/security/CVE-2026-116331/
