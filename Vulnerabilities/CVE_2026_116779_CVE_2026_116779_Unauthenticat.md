# Уязвимость: CVE-2026-116779

## Детали
CVE-2026-116779. Unauthenticated RCE в FreeSWITCH через SIP MESSAGE FreeSWITCH - это открытый программный телефонный коммутатор (softswitch). На нём строят виртуальные АТС, call-центры, VoIP-провайдеров и корпоративную телефонию. У нас он считается одним из двух самых распространённых открытых движков наряду с Asterisk. 9 ноября 2026 года CISA добавила уязвимость в каталог KEV (CVSS 9.8). Выяснилось, что всего один UDP-пакет с SIP MESSAGE на адрес вида api+system id заставляет демон выполнить произвольную команду ОС от своих привилегий. Происходит это потому, что при обработке входящего SIP MESSAGE FreeSWITCH берёт To header field , режет его по первому + , воспринимая всю левую часть как имя chat-протокола. Один из зарегистрированных протоколов - api , который напрямую передаёт данные в switch_api_execute() . Через него доступна, в частности, команда system , выполняющая произвольные команды ОС, а также другие API-команды, например на чтение конфигов, управление звонками, загрузку модулей и т.д. По данным Bitsight, на момент написания поста, в интернете доступно порядка 13 600 открытых инстансов. Уязвимости подвержены все версии < 1.11.3 . ➡️ PoC 💫 @pentestnotes
