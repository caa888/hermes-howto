# Уязвимость: CVE-2026-121481

## Детали
Переполнение буфера в OpenSSL при работе с форматом Base64 В криптографической библиотеке OpenSSL выявлена уязвимость (CVE-2026-121481), приводящая к переполнению буфера из-за целочисленного переполнения при обработке большого объёма данных в функции EVP_EncodeBlock(), предназначенной для кодирования в формате Base64. Исправление пока не принято в кодовую базу OpenSSL. Статус устранения уязвимости в дистрибутивах можно оценить на данных страницах: Debian, Ubuntu, SUSE, RHEL, Gentoo, Arch.
