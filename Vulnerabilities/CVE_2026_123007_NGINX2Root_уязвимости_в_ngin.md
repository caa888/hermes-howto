# Уязвимость: CVE-2026-123007

## Детали
NGINX2Root - уязвимости в nginx, позволяющие выполнить код при использовании HTTP/2 или HTTP/3 Компания Xint выявила пять уязвимостей в nginx, которым присвоено кодовое имя NGINX2Root. Наиболее опасная уязвимость (CVE-2026-123007) позволяет добиться выполнения кода с правами рабочего процесса при приёме на сервере запросов с использованием протокола HTTP/2. Остальные 4 проблемы также допускают удалённое выполнение кода, но проявляются при наличии специфичных настроек или требуют особых условий для эксплуатации. Помимо этого, исследователями из Xint выявлена новая уязвимость в подсистеме SCTP ядра Linux, которая позволяет локальному пользователю получить привилегии root в системе и обойти изоляцию контейнеров. Для всех 5 уязвимостей в nginx подготовлены эксплоиты, которые по цепочке эксплуатируют уязвимости в nginx и в ядре Linux для удалённого выполнения кода с правами root на Linux-сервере.
