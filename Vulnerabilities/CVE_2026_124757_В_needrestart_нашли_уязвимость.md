# Уязвимость: CVE-2026-124757

## Детали
В needrestart нашли уязвимость, которая даёт локальному пользователю права root 17 ноября раскрыли CVE-2026-124757 в needrestart. Эта утилита запускается после обновлений через APT, если пакет установлен, и проверяет, какие службы нужно перезапустить. Исследователь Армаан Сандху обнаружил, что needrestart недостаточно строго проверяет пути cgroup при определении принадлежности процесса к сеансу. Из-за ошибки утилита может принять процесс обычного пользователя за часть сеанса root. Уязвимость подтвердили на Debian 12 и Ubuntu 24.04 LTS. Статус исправлений по версиям пакета можно проверить в трекерах Debian : https://security-tracker.debian.org/tracker/CVE-2026-124757 Ubuntu : https://ubuntu.com/security/CVE-2026-124757
