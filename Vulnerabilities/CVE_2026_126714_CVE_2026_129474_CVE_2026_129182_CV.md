# Уязвимость: CVE-2026-126714, CVE-2026-129474, CVE-2026-129182, CVE-2026-129289, CVE-2026-115560, CVE-2026-129496, CVE-2026-129481

## Детали
🚨 PHP закрывает 18 уязвимостей, включая 7 критических После вчерашнего предупреждения PHP Security Team выпустила обновления безопасности для поддерживаемых веток PHP. Среди исправлений - ошибки управления памятью, обработки HTTP-запросов и сессий, потенциально приводящие к RCE при определенных условиях. 🔬 Семь критических CVE (CVSS 9.2): 1. CVE-2026-129289 - HTTP request smuggling в PHP-FPM при обработке php://input . 2. CVE-2026-129474 - use-after-free, условия эксплуатации требуют уточнения. 3. CVE-2026-129496 - use-after-free при журналировании ошибок и работе с кешем временных зон. 4. CVE-2026-126714 - race condition при записи файлов сессий. 5. CVE-2026-115560 - ошибка в обработке сериализованных данных сессий. 6. CVE-2026-129481 - use-after-free при завершении сессии. 7. CVE-2026-129182 - use-after-free, условия эксплуатации требуют уточнения. ⚠️ Высокий CVSS не означает гарантированную RCE. Для эксплуатации отдельных ошибок необходимы специфические конфигурации или дополнительные условия. 🛡 Что делать: обновить PHP до 8.2.36 / 8.3.37 / 8.4.28 / 8.5.13 . PHP 8.6.0 также включает исправления, но переход на новую ветку требует отдельной проверки совместимости. Для дистрибутивных пакетов учитывать бэкпорты. 🔗 https://www.php.net/ChangeLog-8.php #PHP #CVE #RCE #CyberSecurity
