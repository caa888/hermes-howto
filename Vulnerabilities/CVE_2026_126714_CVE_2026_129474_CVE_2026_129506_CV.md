# Уязвимость: CVE-2026-126714, CVE-2026-129474, CVE-2026-129506, CVE-2026-129182, CVE-2026-129291, CVE-2026-15353, CVE-2026-127960, CVE-2026-129292, CVE-2026-129289, CVE-2026-128090, CVE-2026-129538, CVE-2026-115560, CVE-2026-128064, CVE-2026-129438, CVE-2026-129501, CVE-2026-129496, CVE-2026-129481

## Детали
🔺 Град из 17 уязвимостей в PHP 19 ноября вышли исправления безопасности PHP — в них устранены 17 уязвимостей: 7 c уровнем critical, 4 — high и 6 — moderate. Часть критических уязвимостей ведет к выполнению кода на сервере (RCE), в том числе без аутентификации. Патчи — 8.2.36, 8.3.37, 8.4.28, 8.5.13. На данный момент публичных PoC пока нет. Уязвимости: Critical (9,2 по шкале CVSS 4.0): 🔵 CVE-2026-129289 (FPM) — request smuggling: неаутентифицированный RCE одним запросом. Нужны keep-alive до бэкенда и приложение, открывающее php://input без полного чтения. 🔵 CVE-2026-115560 — рассинхрон сериализаторов сессий, RCE через цепочку гаджетов. 🔵 CVE-2026-129496 — use-after-free в кэше таймзон при старте воркера, RCE. 🔵 CVE-2026-129481 — use-after-free при прерванном завершении сессии, RCE. 🔵 CVE-2026-126714 — склейка частично перезаписанных session-файлов, RCE. 🔵 CVE-2026-129182 — use-after-free в last_fatal_error_backtrace (8.5). 🔵 CVE-2026-129474 — use-after-free в backtrace магических методов (8.5). High: 🔵 CVE-2026-129291 (FPM) — use-after-free в epoll, локальный root (официальные Docker-образы с catch_workers_output=1). 🔵 CVE-2026-127960 — квадратичный DoS на folded-заголовках ответа. 🔵 CVE-2026-128064 — даунгрейд HTTPS:// и FTPS:// до plaintext на смешанном регистре URL. 🔵 CVE-2026-128090 (Phar) — обход проверки OpenSSL-подписи через даунгрейд алгоритма. Moderate: 🔵 CVE-2026-129538 (CGI) — OOB-чтение и запись при коррекции PATH_INFO. 🔵 CVE-2026-129506 (SOAP) — use-after-free при обработке DTD-сущностей. 🔵 CVE-2026-15353 (SOAP) — утечка данных через некорректные размерности массива. 🔵 CVE-2026-129501 (DOM) — double free при сериализации XML. 🔵 CVE-2026-129438 (URI) — некорректная RFC 3986-сериализация на длинном вводе (8.5). 🔵 CVE-2026-129292 (FPM) — XSS на status-эндпоинте. Какие версии уязвимы: 🔵 PHP 8.2–8.5 ниже патчей (8.2.36/8.3.37/8.4.28/8.5.13). Часть багов — только в ветках 8.5 или 8.4. PHP используется примерно на 75% сайтов, так что формально затронуто огромное количество ресурсов. Но каждый баг срабатывает лишь при своем условии: включенные сессии, PHP-CGI, SOAP, Phar, потоковые запросы. Наибольшую опасность представляет FPM-smuggling ( CVE-2026-129289 ): связка PHP-FPM с keep-alive — почти стандарт. Уязвим не каждый сервер. Рекомендуем: 🔵 Обновить PHP до 8.2.36, 8.3.37, 8.4.28 или 8.5.13 — это закрывает все 17 уязвимостей. После обновления обязательно перезапустить PHP-FPM или веб-сервер, иначе старые воркеры остаются уязвимыми. 🔵 Отключить переиспользование соединений с бэкендом на фронте — точечная мера только для CVE-2026-129289 (если апдейт откладывается).
