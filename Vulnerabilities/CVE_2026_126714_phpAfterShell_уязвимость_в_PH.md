# Уязвимость: CVE-2026-126714

## Детали
phpAfterShell: уязвимость в PHP позволяет подменять сессии и потенциально выполнять код на сервере Привет&#33; Исследователи из Depthfirst обнаружили критическую уязвимость CVE-2026-126714 в PHP, получившую 9.2 балла по CVSS 4.0. Проблема затрагивает стандартный механизм хранения сессий в файлах и позволяет подложить в них произвольный сериализованный объект. А при наличии подходящей цепочки gadget’ов это может закончиться выполнением кода на сервере. 👨‍💻 Всё начинается с прерванной записи в файл сессии. PHP не очищает старые данные перед записью, поэтому при аварийном завершении процесса в файле могут смешаться фрагменты новой и предыдущей сессии. Подобрав длины полей, атакующий может заставить PHP при следующем session_start() прочитать старые данные как отдельный объект. 🔴 Один из способов спровоцировать такую запись - функция upload_progress, которая обновляет сессию прямо во время загрузки файла, ещё до запуска кода приложения. Исследователи смогли добиться аварийного завершения процесса посреди записи и получить нужное содержимое сессии. Помимо потенциального RCE, таким способом можно подменять данные об авторизации, правах пользователя и CSRF-токенах. ⚙️ Исправления уже вышли для PHP 8.2.36, 8.3.37, 8.4.28 и 8.5.13, а также в версии 8.6.0. Простое отключение session.upload_progress.enabled закрывает один из путей атаки, но не устраняет саму проблему. Поэтому разработчикам стоит обновить PHP, пересобрать контейнеры и проверить, какая версия реально обслуживает запросы. P.S. По данным исследователей и разработчиков PHP, случаев эксплуатации уязвимости в реальных атаках пока не зафиксировано. #PHP #CVE #RCE #WebSecurity #Infosec 👍 Белый хакер
