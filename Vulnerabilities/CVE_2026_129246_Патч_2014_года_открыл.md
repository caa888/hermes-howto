# Уязвимость: CVE-2026-129246

## Детали
🚀️ ️️️️️ Патч 2014 года открыл путь к root через экран входа в Debian 16 ноября Debian закрыл уязвимость CVE-2026-129246 в LightDM, менеджере графического входа. Исследователь Матко Златич обнаружил, что на уязвимой системе обычный пользователь, уже вошедший в графический сеанс, мог получить права root. lists.debian.org В 2014 году Ив-Алексис Перес добавил в пакет Debian патч, чтобы сократить число служебных каталогов LightDM. Из-за этого экран входа, работающий под непривилегированной учётной записью lightdm, получил доступ на запись туда, где основной процесс LightDM выполнял операции с правами root. Спустя 12 лет Перес сам выпустил бюллетень и удалил свой патч. Обновление разрывает цепочку повышения привилегий до root. Для отдельной проблемы с загрузкой модулей GTK Перес добавил профиль AppArmor в lightdm-gtk-greeter как временную защиту и попросил разработчиков GTK помочь с полноценным исправлением. В Debian 13 (Trixie) исправление вышло в пакете lightdm версии 1.32.0-6+deb13u1.
