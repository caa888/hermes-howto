# Уязвимость: CVE-2026-129496

## Детали
Уязвимость компонента ext-date ядра интерпретатора языка программирования PHP связана с использованием памяти после освобождения. Эксплуатация уязвимости может позволить нарушителю, действующему удаленно, вызвать отказ в обслуживании или выполнить произвольный код BDU:2026-19699 CVE-2026-129496 Использование рекомендаций производителя: https://www.php.net/archive/2026.php Для программных продуктов Red Hat Inc.: https://access.redhat.com/security/cve/cve-2026-129496 Для программных продуктов Debian GNU/Linux: https://security-tracker.debian.org/tracker/CVE-2026-129496 Для программных продуктов Ubuntu: https://ubuntu.com/security/CVE-2026-129496
