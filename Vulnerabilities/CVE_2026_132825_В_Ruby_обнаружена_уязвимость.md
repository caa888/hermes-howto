# Уязвимость: CVE-2026-132825

## Детали
🔺 В Ruby обнаружена уязвимость CVE-2026-132825 с CVSS 7,4 (High) Уязвимость Ruby2Shell (GHSA-34m4-m9fh-gqp5) связана с однобайтовым переполнением буфера при обработке строк в legacy-кодировках. Ошибка затрагивает методы upcase, swapcase, downcase(:fold), capitalize и casecmp?, а также регулярные выражения с флагом /i. Проблема позволяет повредить память процесса и потенциально выполнить код без аутентификации. Однако эксплуатация зависит от раскладки heap, ASLR и поведения приложения. Для атаки нужны: 🔵 Строка в однобайтовой кодировке, например ISO-8859-1. 🔵 Наличие символа ß. 🔵 Нечетная длина строки — не менее 21 байта. 🔵 Вызов уязвимого метода на внешних данных. В Rails атака возможна через multipart-параметр _method : middleware Rack::MethodOverride обрабатывает его до маршрутизации. В classic Sinatra middleware также включен по умолчанию. UTF-8 и ASCII-8BIT не затронуты. Затронуты: 🔵 Ruby 2.4.0–3.3.13. 🔵 Ruby 3.4.0–3.4.12. 🔵 Ruby 4.0.0–4.0.9. 🔵 Ruby 4.1.0-preview1. Исправления уже есть в версиях Ruby 3.3.14, Ruby 3.4.13 и Ruby 4.0.10. Рекомендуем: 🔵 Обновить Ruby и перезапустить сервисы. 🔵 Если пакетный менеджер еще не предлагает исправление, использовать upstream-сборку Ruby. 🔵 Для Rails временно перекодировать _method в UTF-8 до Rack::MethodOverride. 🔵 Проверить версии Ruby в контейнерах и на всех production-хостах. Важно: полностью обновленная Linux-система может оставаться уязвимой, если дистрибутив еще не выпустил исправленный пакет.
