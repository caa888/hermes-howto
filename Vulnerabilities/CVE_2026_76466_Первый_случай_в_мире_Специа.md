# Уязвимость: CVE-2026-76466

## Детали
Первый случай в мире ⚡️ Специалисты F6 зафиксировали эксплуатацию критической уязвимости CVE-2026-76466 в Cisco Expressway. Специалисты Центра кибербезопасности F6 расследовали первый случай эксплуатации критической уязвимости CVE-2026-76466 (CVSS 9,8) в Cisco Expressway. Вскоре после появления общедоступного эксплойта (PoC) злоумышленники успешно атаковали устройства Cisco Expressway X15.5.3, получив возможность удаленно выполнять команды с максимальными привилегиями (root). Как развивалась атака ⬇️ ▪️ Первоначально атакующие скомпрометировали два устройства Cisco Expressway, доступных из интернета, затем через одно из них получили доступ к двум другим узлам кластера, расположенным во внутренней сети организации. ▪️ После получения root-доступа злоумышленники приступили к подготовке инструментария для дальнейшего продвижения по инфраструктуре. Для этого использовались самописные Python-скрипты, предназначенные для сканирования сети, поиска доступных SMB-ресурсов, взаимодействия с SQL Server и WinRM, а также исследования репозиториев GitLab с целью эксфильтрации учетных данных и другой конфиденциальной информации. ‼️ Специалисты F6 установили, что злоумышленники дорабатывали Python-скрипты непосредственно в ходе атаки. В исходном коде обнаружены характерные комментарии и описания исправлений, указывающие на использование ИИ-ассистента. Индикаторы компрометации 🔍 IP-адреса: 66.179.31[.]32 и 18.130.47[.]116 Запись: nodeup,'wombat@127.0.0.1' в журнале Erlang (erlang.log) на устройствах Cisco Expressway Пути: /mnt/harddisk/i{0-9}{4}[a-zA-Z]?/*.py Как выявить признаки эксплуатации ⬇️ Один из ключевых признаков успешной эксплуатации уязвимости — появление записи nodeup,'wombat@127.0.0.1' в системном журнале Erlang (erlang.log) на устройствах Cisco Expressway. Такая запись свидетельствует об установлении соединения с Erlang-узлом, идентификатор которого соответствует известному механизму эксплуатации CVE-2026-76466. При обнаружении подобных событий необходимо проверить другие журналы и артефакты, чтобы подтвердить факт компрометации. Рекомендации ⬇️ 💚 Основной способ защиты — обновление Cisco Expressway до актуальной версии, содержащей исправление уязвимости CVE-2026-76466. Если обновление временно невозможно, рекомендуется ограничить подключения к портам TCP/4371–4372 на межсетевом экране, разрешив доступ только с IP-адресов доверенных узлов кластера. 💚 Компрометация устройства внешнего периметра может открыть путь к критичным системам организации. Поэтому защита должна включать не только своевременное устранение уязвимостей, но и правильно настроенную сегментацию с мониторингом инфраструктуры. 💚 Мониторинг внешнего периметра — заранее выявлять активы с проблемами до их эксплуатации; оценка компрометации покажет, успели ли атакующие воспользоваться проблемой даже после её устранения. 💚 Круглосуточный мониторинг и реагирование — не только раннее обнаружение, но и быстрая локализация и расследование: изоляция систем, оценка масштаба атаки и блокировка дальнейшего продвижения до критичных узлов.
