# Уязвимость: CVE-2026-99288

## Детали
🗄 Уязвимость NoisyTCP позволяет выводить из строя серверы Linux Независимый ИБ-исследователь Хену Ким (Hyunwoo Kim) раскрыл детали уязвимости NoisyTCP (CVE-2026-99288), обнаруженной в сетевой подсистеме ядра Linux и остававшейся незамеченной 11 лет. Баг позволяет удаленному атакующему без аутентификации спровоцировать kernel panic и вывести из строя весь хост. По словам Кима, уязвимость появилась в коде еще 3 октября 2015 года и связана с состоянием гонки при поиске TCP-сокетов в хеш-таблице соединений (ehash). Пока один обработчик пакетов работает с найденным request_sock, другой может успеть освободить этот объект и создать новый по тому же адресу памяти. В результате ядро продолжает работать уже с другим объектом, принимая его за прежний. 🗄 Читать статью — линк . // Не хакинг, а ИБ
