# Уязвимость: CVE-2026-99288

## Детали
Уязвимость NoisyTCP позволяет выводить из строя серверы Linux #cve #Linux Независимый ИБ-исследователь Хену Ким (Hyunwoo Kim) раскрыл детали уязвимости NoisyTCP (CVE-2026-99288), обнаруженной в сетевой подсистеме ядра Linux и остававшейся незамеченной 11 лет. Баг позволяет удаленному атакующему без аутентификации спровоцировать kernel panic и вывести из строя весь хост. По оценке специалиста, проблема затрагивает почти все дистрибутивы Linux.
