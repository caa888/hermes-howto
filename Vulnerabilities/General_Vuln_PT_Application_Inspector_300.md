# Уязвимость: General Vuln

## Детали
PT Application Inspector 3.0.0: ИИ-агент подключается к плагину через MCP На Positive AppSec Conf 18 ноября Positive Technologies объявила об обновлении бесплатных плагинов PT Application Inspector. В версии 3.0.0 появился нативный MCP-сервер (Model Context Protocol), через который плагин подключается к любому ИИ-агенту — OpenCode, Claude Code, Codex, c0wrk. Агент сам запускает проверку проекта или отдельных изменений, читает найденные уязвимости и условия их эксплуатации, предварительно оценивает результат. Статический анализ работает прямо в IDE во время написания кода. Функция AI Hooks проверяет код, который изменил агент: ИИ-анализ действий агента выдаёт разработчику возможные уязвимости без повторного сканирования всего проекта. Подходит проектам, уже прошедшим первичную проверку. How to Fix теперь доступна не только в JetBrains IDE, но и в VS Code: рекомендацию по исправлению выдаёт любая модель с совместимым API, облачная или self-hosted. Исходники можно не отдавать внешним сервисам. *я партнер данной конференции Пресс-релиз Positive Technologies
