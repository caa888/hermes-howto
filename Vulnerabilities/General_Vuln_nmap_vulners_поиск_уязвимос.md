# Уязвимость: General Vuln

## Детали
📂 nmap-vulners: поиск уязвимостей по результатам Nmap Расширение для Nmap, которое сопоставляет обнаруженное ПО с базой Vulners и выводит CVE, оценки CVSS и сведения об известных эксплойтах. Помогает разбирать уязвимости обнаруженных сервисов. Работает без учетной записи и ключа API. Ключ добавляет подробности к результатам. Для работы необходимо определение ПО средствами Nmap: одного списка открытых портов недостаточно. Важно учитывать, что сведения о ПО проверяемой системы отправляются стороннему сервису . ℹ️ Открыть репозиторий 📂 ИБ Книга // max.ru/itbook_library
