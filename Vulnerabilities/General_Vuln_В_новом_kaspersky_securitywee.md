# Уязвимость: General Vuln

## Детали
В новом #kaspersky_securityweek : 🟢 Злоумышленники взяли на вооружение открытую платформу ARTEX — автор создавал её для анализа защищённости систем, но был вынужден удалить проект с GitHub из-за волн реальных атак. В связке с большими языковыми моделями инструмент обходит проверку личности с помощью поддельных видео и помогает развивать атаки внутри корпоративных сетей. Исследователям компании Amazon удалось заманить атакующих в специальные ловушки и перехватить их текстовые инструкции для искусственного интеллекта. 🟢 Применение ИИ привело к лавинообразному росту числа найденных уязвимостей — в 2026 году их зарегистрировано уже больше ста тысяч, что вдвое превышает показатели прошлого года. Поскольку средства для взлома с помощью ИИ тоже создаются намного быстрее, команда Google Project Zero решила пересмотреть многолетние правила и жёстко сократить время, которое даётся разработчикам на исправление ошибок. 🟢 Эксперты «Лаборатории Касперского» изучили новые приёмы группировки Citrus Ransomware, поделились тонкостями проверки облачных систем на проникновение и проанализировали реальные атаки через штатные механизмы ESXi и vCenter.
