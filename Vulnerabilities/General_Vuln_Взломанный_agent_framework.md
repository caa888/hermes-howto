# Уязвимость: General Vuln

## Детали
🗡️ Взломанный agent-framework от Microsoft крал токены Azure и GitHub из CI | Привет, друг. На связи Эллиот. Какие версии agent-framework на PyPI были вредоносными, что они крали и как проверить свои окружения и CI. 17 ноября на PyPI вышли две вредоносные версии agent-framework — официального Python-пакета Microsoft для сборки ИИ-агентов: 1.26.1 и 1.26.2 запускали стилер, который пытался забрать ключи облаков, токены CI и файлы с паролями с каждой машины, где их установили. Версии продержались на PyPI меньше часа и удалены, последняя чистая — 1.26.0, говорится в advisory PYSEC-2026-4388 в базе OSV. ⏺ Ссылка на чтиво #News #Malware #Privacy | Mr. Robot
