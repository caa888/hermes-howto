# Уязвимость: General Vuln

## Детали
🦀 Сколько уязвимостей curl мог бы предотвратить Rust? Из 81 уязвимости, подтверждённой в curl с начала 2026 года, 14, вероятно, можно было бы избежать с помощью языка с безопасным управлением памятью. Это 17,3% по подсчётам создателя curl Даниэля Стенберга. Причины остальных 67, по его оценке, сохранились бы и при переносе на Rust. Поводом для подсчёта стали две реализации curl и libcurl на Rust, написанные с помощью ИИ-агентов. Одна называется urlx, вторая сохранила имя curl. У агентов уже были исходники, подробная документация и тысячи тестов, по которым можно проверить поведение новой реализации. По подсчётам Стенберга, за три с небольшим недели агенты превратили 185 тысяч строк C в 340 тысяч строк Rust. За тот же срок оригинальный curl принял свыше 300 коммитов, включая более 200 исправлений ошибок. Стенберг задаётся вопросом, смогут ли новые проекты выпускать исправления в том же темпе. Сам Стенберг предпочитает постепенно улучшать и рефакторить curl. В комментариях он добавил, что уверенность при изменении кода ему дают архитектура, тесты и инструменты, а выбор C, по его опыту, не мешал добавлять новые функции. https://daniel.haxx.se/blog/2026/11/17/actual-curl-rewrites-in-rust/
