# Уязвимость: General Vuln

## Детали
Уязвимость платформы для работы с кодом GitFlic связана с непринятием мер по ограничению пути при распаковке tar.gz-архива в механизме импорта проектов из GitLab. Эксплуатация уязвимости может позволить нарушителю, действующему удаленно и имеющему привилегии импорта проекта, создавать и перезаписывать файлы за пределами каталога распаковки (Zip Slip) BDU:2026-19333 Использование рекомендаций: Для GitFlic: Обновление программного обеспечения до версии 5.2.2
