# VULN: Microsoft представила MAI Cyber 2 Flash


![Иллюстрация](//telegram.org/img/emoji/40/E29DA4.png)


## Содержание
Microsoft представила MAI Cyber 2 Flash для задач кибербезопасности Модель предназначена для поиска уязвимостей, рекомендаций по их исправлению и расследования угроз. Её контекстное окно составляет 1 миллион токенов. Microsoft планирует использовать модель только в собственных продуктах безопасности. В Codename MDASH она должна автоматически заменить предыдущую модель в профиле MAI для подходящих клиентов начиная с середины декабря. По внутренней оценке Microsoft, на CyberGym-E2E модель решила 92,3% задач против 91,5% у GPT-6 Astra, используя вдвое меньший бюджет рассуждений. Оценка проходила офлайн на 813 из 905 задач: ещё 92 исключили из-за совпадений источников с тренировочными данными. В этом тесте расчётная стоимость токенов на задачу составила менее 2% от стоимости GPT-6 Astra. Этот расчёт относится к конкретному тесту и не отражает цену для клиента.
