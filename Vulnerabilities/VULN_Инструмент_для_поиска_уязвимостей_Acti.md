## Содержание
🤒 Инструмент для поиска уязвимостей Active Directory Certipy – инструмент с открытым исходным кодом, предназначенный для анализа безопасности Active Directory Certificate Services. С помощью Certipy можно проводить аудит центров сертификации, выявлять уязвимые шаблоны сертификатов, проверять потенциальные векторы повышения привилегий и исследовать уязвимости ESC1–ESC17. — Инструмент автоматизирует многие процессы анализа AD CS и предоставляет результаты, которые помогают оценить уровень защищённости доменной среды. 💬 https://github.com/ly4k/Certipy #Pentesting #ActiveDirectory #EthicalHacking Secure Sector .
